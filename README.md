# nixos-config

NixOS configuration managed with Flakes, structured with
[flake-parts](https://flake.parts) and the dendritic pattern: every file under
`modules/` is a flake-parts module (auto-loaded with
[import-tree](https://github.com/vic/import-tree)) that registers NixOS modules
as `flake.modules.nixos.<name>`. Nothing imports files by path.

## Layout

| File | Registers |
|---|---|
| `modules/base.nix` | `base`: locale, boot, networking, users, core tools (every host) |
| `modules/storage.nix` | `storage`: disko layout (LUKS + LVM + XFS) |
| `modules/hardware.nix` | `hw-vm`, `hw-laptop`, `hw-nvidia` (mixin) |
| `modules/desktops.nix` | `desktop-gnome`, `desktop-kde`, `desktop-sway` |
| `modules/roles.nix` | `role-norm`, `role-geek` (`geek` = `norm` + development features) |
| `modules/hosts.nix` | builds a `nixosConfiguration` for every `hosts/<name>/` |
| `hosts/<name>/hardware.nix` | generated by `nixos-generate-config` |
| `hosts/<name>/install-args.nix` | per-host selection of the axes below, plus disk sizes |

A host is `base` + `storage` + one **hardware** + one **desktop** + one **role**
(+ optional `nvidia` mixin), selected in `hosts/<name>/install-args.nix`:

```nix
{
  name = "vm001";
  hardware = "vm";       # vm | laptop
  nvidia = false;        # adds hw-nvidia
  desktop = "gnome";     # gnome | kde | sway
  role = "norm";         # norm | geek
  diskDevice = "/dev/vda";
  rootSize = "10G";
  swapSize = "4G";
}
```

## Installing NixOS with Flake

1. boot with the NixOS minimal ISO installer image into an interactive shell
2. clone this repository
3. run the [`scripts/install.sh`](scripts/install.sh) script which does the steps described below:

   ```bash
   sudo scripts/install.sh [-d gnome|kde|sway] [-r norm|geek] [-n] <hostname> <vm|laptop> <disk-device>
   ```

   During the installation, you will be asked to provide two passwords, one for the first `nixadmin` user and the other for LUKS disk encyption.

4. reboot the system once the installation is completed. In the rebooted system, the repository including the generated files for the device can be found un `/etc/nixos/nixos-config`.

## Updating an existing system

After making changes to the configuration, rebuild and switch:

```bash
sudo nixos-rebuild switch --flake /etc/nixos/nixos-config#vm001
```

To upgrade to the latest packages pinned in the flake:

```bash
nix flake update /etc/nixos/nixos-config
sudo nixos-rebuild switch --flake /etc/nixos/nixos-config#vm001
```

## Adding a new host

Create `hosts/<hostname>/hardware.nix` (from `nixos-generate-config`) and
`hosts/<hostname>/install-args.nix` (see [Layout](#layout)), or let
`scripts/install.sh` generate both. Hosts are discovered automatically; no
change to `flake.nix` is needed.

## Adding a new desktop, role or hardware profile

Add `flake.modules.nixos.desktop-<name>` (or `role-<name>`, `hw-<name>`) to the
matching file under `modules/`, then use `<name>` in `install-args.nix`.
