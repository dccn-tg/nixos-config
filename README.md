# nixos-config

NixOS configuration managed with Flakes, structured with
[flake-parts](https://flake.parts) and the dendritic pattern: every file under
`modules/` is a flake-parts module (auto-loaded with
[import-tree](https://github.com/vic/import-tree)) that registers NixOS modules
as `flake.modules.nixos.<name>`. Nothing imports files by path.

## Layout

| File | Registers |
|---|---|
| `modules/base.nix` | `base`: locale, boot, networking, users, core tools (every host) |
| `modules/storage.nix` | `storage`: disko layout (LUKS + LVM + XFS) |
| `modules/hardware.nix` | `hw-vm`, `hw-laptop`, `hw-nvidia` (mixin) |
| `modules/desktops.nix` | `desktop-gnome`, `desktop-kde`, `desktop-sway` |
| `modules/roles.nix` | `role-norm`, `role-geek` (`geek` = `norm` + development features) |
| `modules/hosts.nix` | builds a `nixosConfiguration` for every `hosts/<name>/` |
| `hosts/<name>/hardware.nix` | generated by `nixos-generate-config` |
| `hosts/<name>/install-args.nix` | per-host selection of the axes below, plus disk sizes |

A host is `base` + `storage` + one **hardware** + one **desktop** + one **role**
(+ optional `nvidia` mixin), selected in `hosts/<name>/install-args.nix`:

```nix
{
  name = "vm001";
  hardware = "vm";       # vm | laptop
  nvidia = false;        # adds hw-nvidia
  secureboot = false;    # optional, adds secureboot (lanzaboote, experimental)
  desktop = "gnome";     # gnome | kde | sway
  role = "norm";         # norm | geek
  diskDevice = "/dev/vda";
  rootSize = "10G";
  swapSize = "4G";
}
```

The `install-args.nix` file is generated by the [installer script](scripts/install.sh).  There is no need to create this file manually.

## Installing NixOS with Flake

1. boot with the NixOS minimal ISO installer image into an interactive shell
2. setup network connection on the device
3. clone this repository
4. run the [`scripts/install.sh`](scripts/install.sh) script which does the steps described below:

   ```bash
   sudo scripts/install.sh [-d gnome|kde|sway] [-r norm|geek] [-s root-size-gb] [-n] <hostname> <vm|laptop> <disk-device>
   ```

   The `-s` option sets the root partition size in GB (default: `10`). The swap size is derived from the amount of RAM. The installation fails if root + swap exceeds the disk size minus 10 GB.

   During the installation, you will be asked to provide two passwords, one for the first `nixadmin` user and the other for LUKS disk encyption.

5. reboot the system once the installation is completed. In the rebooted system, the repository including the generated files for the device can be found in `/etc/nixos/nixos-config`.

## Secure Boot (optional, experimental)

Secure Boot uses [lanzaboote](https://github.com/nix-community/lanzaboote), which is
still considered unstable, so it is off by default. To enable it on a host:

1. set `secureboot = true;` in `hosts/<name>/install-args.nix`
2. create the signing keys: `sudo nix run nixpkgs#sbctl -- create-keys` (stored in `/var/lib/sbctl`)
3. rebuild and switch, then check with `sudo sbctl verify`
4. put the firmware in Setup Mode and run `sudo sbctl enroll-keys --microsoft`
   __note:__ you may need to add `--ignore-immutable` option in case the command gives _File is immutable_ error.
6. reboot and enable Secure Boot in the firmware

Set the flag back to `false` and rebuild to return to systemd-boot.

## Updating an existing system

After making changes to the configuration, rebuild and switch:

```bash
sudo nixos-rebuild switch --flake "/etc/nixos/nixos-config#$(hostnamectl hostname)"
```

To upgrade to the latest packages pinned in the flake:

```bash
nix flake update --flake /etc/nixos/nixos-config
sudo nixos-rebuild switch --flake "/etc/nixos/nixos-config#$(hostnamectl hostname)"
```

## Adding a new host

The hardware and installation arguments for a new host are automatically generated by the [installer script](scripts/install.sh) and added (but not committed) to the local git repository under the [`hosts`](hosts) directory.
